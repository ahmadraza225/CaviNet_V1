# CaviNet V1

AI decision support for differentiating **pulmonary tuberculosis (TB)** from
**non-tuberculous mycobacterial (NTM) lung disease** on chest CT, with a calibrated
confidence score. Final Year Project, Air University Islamabad (2025–2027).

> Research prototype: decision support only, not a diagnosis.
